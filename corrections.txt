1. CONTEXTE DE BIFAUMA
==================================================

BIFAUMA est une entreprise spécialisée dans :

* l'octroi de prêts ;
* les solutions de financement ;
* l'accompagnement des particuliers et/ou entreprises dans leurs besoins de financement ;
* l'accompagnement des projets nécessitant un financement.

Le site doit donc présenter BIFAUMA comme une entreprise de financement et de prêt sérieuse, professionnelle, accessible et rassurante.

NE PAS présenter BIFAUMA comme :

* une banque traditionnelle si ce n'est pas juridiquement le cas ;
* une société d'investissement si ce n'est pas son activité ;
* une plateforme de trading ;
* une société de gestion d'actifs ;
* un intermédiaire financier avec des services qui n'existent pas réellement.

Le vocabulaire du site doit rester cohérent avec les activités réelles de BIFAUMA.

Le message principal doit être orienté vers :

* le financement ;
* les prêts ;
* les projets ;
* l'accompagnement ;
* la simplicité de la demande ;
* la confiance.

3. RESPONSIVE DESIGN — PRIORITÉ ABSOLUE
=======================================

Le site doit être parfaitement responsive sur :

* mobile : 320px à 767px ;
* tablette : 768px à 1023px ;
* desktop : 1024px à 1439px ;
* grands écrans : 1440px et plus.

Ne fais pas simplement une version desktop réduite sur mobile.

Le design doit être pensé pour chaque format.

Tester notamment :

* 320px ;
* 360px ;
* 375px ;
* 390px ;
* 414px ;
* 768px ;
* 1024px ;
* 1280px ;
* 1440px ;
* 1920px.

4. CORRECTIONS MOBILE
=====================

Sur mobile :

* aucun élément ne doit dépasser horizontalement de l'écran ;
* aucun scroll horizontal ne doit apparaître ;
* les textes doivent être parfaitement lisibles ;
* les titres ne doivent pas être coupés ;
* les boutons doivent être suffisamment grands pour être facilement touchés ;
* les marges latérales doivent être cohérentes ;
* les sections doivent avoir une hauteur naturelle ;
* les images doivent rester proportionnées ;
* les cartes doivent s'empiler correctement ;
* les formulaires doivent être parfaitement utilisables ;
* les champs doivent avoir une hauteur confortable ;
* les boutons doivent être suffisamment espacés ;
* les éléments décoratifs ne doivent pas casser la mise en page.

Évite les valeurs fixes qui provoquent des débordements.

Utilise lorsque nécessaire :

* max-width ;
* width: 100% ;
* min-width: 0 ;
* flex-wrap ;
* CSS Grid responsive ;
* clamp() pour les tailles de texte ;
* media queries appropriées.
