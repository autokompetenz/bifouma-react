# REFONTE COMPLÈTE DU SITE BIFAUMA — UX/UI PREMIUM + FINANCEMENT

Tu travailles sur le projet React/Vite existant de BIFAUMA.

Je veux une **refonte complète du site**, aussi bien sur le plan visuel que sur le plan UX/UI, tout en conservant les fonctionnalités, les routes et surtout le contenu métier existant.

Le résultat doit donner l'impression d'un **véritable site professionnel de financement et de crédit**, et non d'un template SaaS, d'une startup technologique ou d'un site générique.

---

# 1. RÈGLE PRINCIPALE

NE PAS repartir de zéro fonctionnellement.

Tu dois :

* analyser tout le projet existant avant de modifier quoi que ce soit ;
* conserver l'architecture React/Vite lorsqu'elle est saine ;
* conserver les routes existantes ;
* conserver les traductions existantes ;
* conserver les formulaires et leurs fonctionnalités ;
* conserver les contenus métier existants ;
* améliorer considérablement la présentation, la hiérarchie, l'UX, le responsive et la crédibilité visuelle ;
* supprimer les éléments visuels qui donnent une impression de template ou de SaaS ;
* ne pas inventer de nouvelles informations commerciales ;
* ne pas inventer de partenaires ;
* ne pas inventer de certifications ;
* ne pas inventer de chiffres ;
* ne pas inventer de clients ;
* ne pas inventer de témoignages ;
* ne pas inventer de performances financières.

Le contenu existant est la source de vérité.

Si un texte est déjà présent dans `src/i18n.jsx`, `src/data`, les pages ou les composants, utilise-le.

# 43. APPROCHE UX

Utilise les principes professionnels de UX Design :

### Clarté

Le visiteur comprend immédiatement le service.

### Hiérarchie

Chaque section a une fonction.

### Réassurance

Les informations importantes sont visibles au bon moment.

### Réduction de friction

La demande de financement doit être simple.

### Progressivité

Ne pas demander toutes les informations immédiatement.

### Feedback

Chaque action utilisateur doit produire un retour clair.

### Cohérence

Même composant = même comportement partout.

### Accessibilité

Le site doit être utilisable par le plus grand nombre.

### Conversion

Les CTA sont présents mais jamais agressifs.

Ne fais pas une simple retouche CSS.

Le principe est :

> Même entreprise.

> Même fonctionnalités principales.

> Beaucoup plus professionnel.

5. les problèmes responsive corrigés ;
